# GitHub Profile Finder

A Python command-line application that retrieves GitHub profile information using the GitHub API.

## Features

* Search for a GitHub user by username
* Display username
* Display followers
* Display following count
* Display public repositories
* Display GitHub profile URL
* Handles API and connection errors

## Technologies Used

* Python
* Requests
* REST API
* JSON

## API

This project uses the GitHub REST API to retrieve public profile information.

## Example

```text
Enter Your GitHub Username: octocat

Username: octocat
Followers: 24339
Following: 9
Public Repositories: 8
Profile URL: https://github.com/octocat
```
