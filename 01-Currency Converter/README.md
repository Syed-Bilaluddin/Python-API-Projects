# Currency Converter

A Python command-line application that converts an amount from one currency to another using a currency exchange rate API.

## Features

* Enter an amount to convert
* Select the source currency
* Select the target currency
* Retrieve current exchange rates from an API
* Calculate the converted amount
* Handles invalid amounts
* Handles invalid currencies
* Handles API and connection errors

## Technologies Used

* Python
* Requests
* REST API
* JSON
* Exception Handling

## API

This project uses the ExchangeRate-API to retrieve currency exchange rates.

## Example

```text
Amount: 100
From: USD
To: PKR

100 USD = 27800 PKR
```
