# Random Quote Generator

A Python command-line application that retrieves a random inspirational quote using an online API.

## Features

* Retrieves a random quote from an API
* Displays the quote
* Displays the author
* Handles API connection errors
* Handles timeout errors
* Handles other request errors

## Technologies Used

* Python
* Requests
* REST API
* JSON
* Exception Handling

## API

This project uses the ZenQuotes API to retrieve random quotes.

## Example

```text
Courage is knowing what not to fear.

— Plato
```
